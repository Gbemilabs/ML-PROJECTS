## New Finding: Adversarial-Validation Artifact

The prior train-vs-test logistic classifier reported OOF AUC 0.999992. This was not real distribution separation. `GarageCars` was stringified independently in train and test after the test column became floating-point due to a missing value: train labels looked like `2`, test labels like `2.0`. The classifier identified the serialization source. Removing `GarageCars` dropped AUC to 0.514; the original numeric representation without this categorical string conversion gave chance-level AUC.

Both `train.py` and `experiments/phase2.py` now canonicalize integer-coded categorical values via nullable integer strings and preserve missing values as `Missing`. Re-running the exact phase-two adversarial helper gives mean AUC 0.515489 and pooled AUC 0.515209. No distribution reweighting should be based on the old AUC. Remaining test-only category levels (`GarageCars` 5/Missing, `Fireplaces` 4, `MSSubClass` 150, and `TotRmsAbvGrd` 13/15) appear to be genuine sparse levels, not source-label fingerprints.

A paired 5-fold XGBoost counterfactual used the same fitted fold models and changed only validation `GarageCars` strings from canonical integer labels to decimal-form labels. Pooled RMSE changed from 0.129112 to 0.131353 and mean absolute prediction change was 0.014428 in log-price space. This is a preprocessing robustness experiment, not an estimate of leaderboard gain. The regularized XGBoost model's separate 5x2 repeated-KFold run averaged 0.124369 over fold RMSEs (std 0.013851; worst fold 0.149489); without a repeated baseline comparison it is not promoted.

## New Finding: Test-Matched Edwards Archetype

Baseline OOF residuals identify two severe overpredictions: IDs 524 and 1299 are recent, quality-10 Edwards new-construction sales (`SaleType=New`, `SaleCondition=Partial`) with prices $184,750 and $160,000. Test ID 2550 has the same semantic profile, is also new/partial, and has 5,095 square feet of above-grade living area. It is the only test home above 4,000 square feet.

Excluding IDs 524 and 1299 from every regularized-XGBoost training fold improved pooled OOF RMSE from 0.129112 to 0.127188, mainly on other houses. However, an all-data fit then raised the matching test home's estimate from about $316k to $642k. Because the test set contains a close archetype match, global deletion is not justified; the observations remain in the training data.

The standalone `experiments/phase3_archetype.py` tests a fold-local target-mean correction for this semantic group. Across five seeds of repeated 5-fold splits, 18 of 20 held-out group appearances had a group peer in the training fold. Applying the peer-only log-target mean to the preserved baseline OOF predictions reduced repeated pooled RMSE from 0.125466 to 0.118528 and group-only RMSE from 1.181 to 0.397. The generated OOF file is `experiments/edwards_archetype_oof.csv`; the candidate submission is `experiments/edwards_archetype_candidate_submission.csv`, assigning test ID 2550 a price of about $171,930. This result is exploratory, not an unbiased generalization estimate: it concerns two unique homes, and the archetype was selected after inspecting residuals and test features. No candidate is promoted from it.

A broader fold-local target encoding over Neighborhood x OverallQual x SaleType x SaleCondition x recent-build era was tested as a negative control. Across five seeds of repeated 5-fold partitions, all tested shrinkage levels from 0.5 to 50 worsened pooled RMSE; even the least harmful result was 0.129313 versus 0.125466. Reject a general target-mean blend. The exact Edwards group remains an isolated specialist hypothesis, not evidence for a broad encoding layer.

The canonicalized full-data submission (`experiments/canonicalized_baseline_submission.csv`) changes predictions materially: mean log-price shift -0.010622 and mean absolute shift 0.023004 against the historical submission. For test ID 2550, historical and canonicalized prices are about $264,246 and $281,091. Training-side preprocessed feature values exactly match the historical pipeline. The user confirmed this file was the submission that earned 0.12654 / ~#1084; it is preserved under `experiments/champion/`. Kaggle CLI and credentials are absent, so the result could not be independently queried.
