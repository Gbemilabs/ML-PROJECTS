# Shadow Candidates

Files in this directory are experimental only. They are not externally submitted, not promoted, and must never replace root `submission.csv` without a documented champion challenge and explicit promotion decision.

## `hierarchical_residual_xgb.csv`

- Generated by `experiments/phase4_hierarchical_residual.py` from regularized XGBoost plus a neighborhood×quality residual offset.
- Initial five-seed XGBoost confirmation looked positive, but the support-floor negative control invalidated the general-effect interpretation: the gain vanished when requiring two training peers and worsened at higher support.
- The effect is strongly influenced by singleton cells, including Edwards×quality-10. It moves test ID 2550 by about -$29k relative to the protected champion prediction.
- Decision: rejected for promotion. Retained only as reproducibility/audit evidence; do not submit.

## Phase Six Shadows

- `phase6_uncertainty_gate.csv`: an uncertainty-triggered incremental correction selected at the 90th percentile. It worsened confirmation champion-OOF RMSE from 0.123932 to 0.124194; rejected.
- `phase6_leaf_residual.csv`: XGBoost tree-leaf residual neighbors. Aggregate confirmation improved, but excluding the two Edwards rows reduced the gain to 0.000089 with a paired-bootstrap interval crossing zero; test ID 2683 moved by +$74,668. Rejected for promotion.

Both files are valid experiment artifacts only. The current external champion remains `experiments/champion/submission_0.12374.csv` and root `submission.csv` must not be replaced by either shadow.
